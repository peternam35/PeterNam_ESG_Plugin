파일 경로는 이 SKILL.md가 있는 폴더 기준입니다. references/core/NN.md, references/pool/NN.md와 methodology/ 경로를 사용합니다. index.md의 core/NN.md는 references/core/NN.md로 읽습니다. 런타임이 파일 경로 읽기를 제공하지 않으면 동봉 리소스에서 같은 파일을 조회하고, 접근 불가하면 그 사실을 알립니다. 호스트 컴퓨터의 원본 폴더에 접근하지 않습니다.



# 글 교정

사용자의 현재 요청 또는 담당자가 붙여넣은 문장·문단을 대상으로 한다.

## 이 스킬이 하지 않는 것

- 필수기재항목 충족 여부 판정 — 그건 `check` 스킬의 역할이다
- 문서 간 정합성 판정 — 그건 `crosscheck` 스킬의 역할이다
- 내용을 새로 지어내거나 수치를 추정하는 것
- 전문용어를 쉬운 말로 바꿔치기하는 것 — 이 스킬은 용어를 지우지 않고 그 옆의 설명만 쉽게 만든다

## 규칙 1 — 용어는 그대로, 설명만 쉽게

- 법령명·국제기준명·이니셔티브명·지표명(예: `UNGP`, `ESRS S1`, `EcoVadis`, `근로기준법 제6조`)은 원문 그대로 유지한다. 임의로 순화하거나 다른 말로 바꾸지 않는다
- 그 용어를 설명하는 문장은 **중학생·고등학생이 읽고 이해할 수 있는 수준**으로 풀어쓴다. 어려운 한자어·수동태·중첩된 종속절을 피하고, 짧은 문장으로 끊는다
- 용어와 설명이 이미 붙어 있는 구조는 유지한다. 용어를 지우고 설명만 남기지 않는다

## 규칙 2 — 표제번호 체계 (이모티콘 금지)

문서 안에서 번호를 매길 때 아래 5단계만 쓴다. 순서를 바꾸지 않는다.

| 단계 | 형식 | 예 |
|---|---|---|
| 1 | `1` `2` `3` | 1. 인권경영 정책 |
| 2 | `1)` `2)` `3)` | 1) 실사 절차 |
| 3 | `(1)` `(2)` `(3)` | (1) 자사 사업장 |
| 4 | `①` `②` `③` | ① 강제노동 |
| 5 | `-` | - 세부 항목 |

**이모티콘·기호형 불릿(✅ 📌 🔹 등)은 표제번호로도 목록 기호로도 쓰지 않는다.** 이 표의 5단계 밖의 기호를 새로 만들지 않는다.

**단계를 내려가는 것은 포함관계가 있을 때만이다.** 항목들이 같은 층위의 병렬 목록이면(서로를 포함하지 않으면) 1단계 번호만 반복해서 쓴다 (`1` `2` `3` `4`). 원문에 포함관계가 명시돼 있지 않은데 임의로 하위 단계를 붙여 포함관계처럼 보이게 만들지 않는다 — 애매하면 병렬로 취급하고, 어느 쪽인지 담당자에게 확인한다.

## 출력 형식

원문의 문단 구분·표 구조는 유지하면서 위 두 규칙만 적용해 다시 쓴다. 무엇을 바꿨는지 원문과 대조해 설명하지 않는다 — 결과물만 제시한다.

**규칙을 설명하는 문장으로 답을 대신하지 않는다.** "병렬 항목이므로 같은 단계 번호를 적용하면 됩니다" 같은 문장만 쓰고 끝내는 것은 오답이다 — 번호가 실제로 붙은 목록 그 자체를 반드시 출력한다. 예:

- 담당자: "안전보건 교육, 인권 교육, 윤리 교육, 정보보안 교육은 병렬입니다. 번호 매겨줘"
- 오답: "병렬 항목이므로 같은 단계 번호를 적용하면 됩니다." (규칙만 말하고 목록을 안 냄)
- 정답:
  ```
  1. 안전보건 교육
  2. 인권 교육
  3. 윤리 교육
  4. 정보보안 교육
  ```
