## 설계 권고

**[I] 사내 확정 전까지는 권고다.**

1. **공시 6개 항목과의 매핑표를 필수기재항목에 넣는다.** 이 문서는 2026-08-01부로 사내 결재 문서에서 외부 공시자료의 원천으로 성격이 바뀌었다. 지금 구조는 내부 보고용으로만 설계되어 있다
2. **안전보건 투자액을 회계상 분리 집계한다.** 공시 항목 중 "안전보건에 관한 투자"는 안전 관련 비용이 다른 운영비와 섞여 있으면 작성할 수 없다
3. **수급인 데이터 수집 체계를 계획에 포함한다.** 관계수급인 사망사고 현황이 공시 대상이므로 도급업체 안전보건 관리 계획에 수집 경로가 있어야 한다
4. **위험성평가 증빙을 실시 → 근로자 참여 → 개선조치 → 공유 → 3년 보존의 5단계로 잡는다.** 과태료 부과 시점(50인 이상 2027-01)까지 체계를 갖춘다
5. **4월 30일 공시 기한을 작성 마감에 연결한다.** 현재 주기가 연 1회로만 잡혀 있어 기한 역산이 없다
